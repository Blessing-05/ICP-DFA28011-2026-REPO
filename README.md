# Project Implementation Approach

Before beginning the internship projects, I revisited the AWS Management Console to refresh my understanding of the core services and their configurations. This review helped reinforce concepts such as networking, security, and database deployment while rebuilding familiarity with the AWS interface.

For the implementation phase of this internship, I chose to build my projects using **Terraform** instead of relying solely on the AWS Management Console.

This decision was made to strengthen my Infrastructure as Code (IaC) skills by:

- Automating cloud infrastructure deployments.
- Writing reusable and maintainable infrastructure code.
- Gaining hands-on experience with industry-standard cloud automation practices.
- Improving my understanding of Terraform resource dependencies and state management.
- Building practical skills that are widely used in modern Cloud Engineering and DevOps environments.

While the AWS Management Console remains valuable for understanding how AWS services work, implementing these projects with Terraform provides a deeper understanding of infrastructure automation and aligns with my professional goal of developing expertise in Cloud Engineering and Cloud Security.
