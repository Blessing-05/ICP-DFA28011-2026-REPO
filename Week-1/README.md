# Week 1 – Foundation and Project Selection

## Overview

Week 1 focused on preparing the environment for the Cloud Computing InternCareerPath Internship Program. Rather than deploying cloud resources immediately, this week was dedicated to reviewing the internship requirements, organizing the project repository, preparing the development environment, and selecting the projects that will be completed throughout the internship.

This preparation provides a solid foundation for implementing secure and well-documented cloud infrastructure in the coming weeks.

---

## Objectives

- Review the internship requirements and deliverables.
- Prepare the AWS development environment.
- Set up Git and GitHub for version control.
- Organize the project repository.
- Select the internship projects.
- Prepare the local environment for Infrastructure as Code (IaC) development.

---

## Activities Completed

- Reviewed the internship guide and project requirements.
- Organized the GitHub repository using the required weekly folder structure.
- Created documentation files for Week 1.
- Prepared the AWS environment for future deployments.
- Verified the local development tools, including Git, Visual Studio Code, and Terraform.

## Project Implementation Approach

Before beginning the implementation phase, I revisited the AWS Management Console to refresh my understanding of core AWS services and their configurations.

Although these projects can be deployed through the AWS Management Console, I chose to implement them using **Terraform** to strengthen my Infrastructure as Code (IaC) skills and gain practical experience with automated cloud provisioning.

This approach supports my goal of developing stronger cloud engineering and cloud security skills while following modern infrastructure automation practices.
