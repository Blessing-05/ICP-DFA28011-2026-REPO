# Project Selection

## Overview

Following a review of the available projects within the InternCareerPath Project Bank, two projects were selected for implementation during this internship.

The selected projects align closely with modern cloud engineering practices while supporting the development of practical skills in cloud networking, infrastructure automation, and secure resource deployment.

The primary implementation tool for both projects will be Terraform to strengthen Infrastructure as Code (IaC) capabilities.

---

# Selected Projects

## Project 3 – VPC Network Architecture

### Problem Statement

Modern cloud applications require secure, isolated, and scalable network environments capable of supporting production workloads.

Amazon Virtual Private Cloud (Amazon VPC) provides complete control over networking resources including IP addressing, routing, internet connectivity, and security controls.

---

### Project Objective

Design and deploy a production-style Virtual Private Cloud using Terraform.

The infrastructure will include:

- Virtual Private Cloud (VPC)
- Public Subnets
- Private Subnets
- Internet Gateway
- NAT Gateway
- Route Tables
- Route Table Associations
- Security Groups
- EC2 Instances (if required)

---

### Skills to be Developed

This project will strengthen practical knowledge in:

- AWS Networking
- Cloud Security
- Infrastructure as Code
- Secure Architecture Design
- Terraform Resource Dependencies
- Cloud Resource Management

---

### Expected Outcome

At project completion, the environment should provide a secure and scalable AWS network architecture capable of supporting future cloud workloads.

# Project 4 – Managed Database Deployment

### Problem Statement

Production databases require secure deployment, automated backup strategies, high availability, and controlled network access.

Amazon RDS simplifies database administration while improving operational reliability.

---

### Project Objective

Deploy a secure Amazon RDS database using Terraform.

The implementation will include:

- Amazon RDS
- DB Subnet Groups
- Security Groups
- Backup Configuration
- Private Network Connectivity
- Secure Database Access

---

### Skills to be Developed

- Database Administration
- Cloud Storage Concepts
- Secure Database Networking
- Infrastructure Automation
- Disaster Recovery Planning

---

### Expected Outcome

A managed relational database deployed securely within the AWS environment using Infrastructure as Code.

# Why Terraform?

Although many AWS resources can be provisioned manually through the AWS Management Console, this internship will prioritize Infrastructure as Code using Terraform.

Terraform offers several advantages:

- Repeatable deployments
- Automated infrastructure provisioning
- Version-controlled infrastructure
- Reduced manual configuration errors
- Faster deployment of cloud environments
- Improved collaboration and documentation

Developing Terraform skills also aligns with current industry practices for cloud engineering and DevOps.
